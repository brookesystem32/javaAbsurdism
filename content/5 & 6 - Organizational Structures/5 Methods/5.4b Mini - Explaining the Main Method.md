## Syntax
```java
public static void main(String[] args){
	System.out.println("The Final Boss");
}
```
Alright, now it's time to understand the most evil part of java programming: *The weird syntax for the main method.* 

Here we'll utilize all the concepts that we learned so far in order to understand this thing! The module is primarily going to be a *"challenge"* one, it's not really practical to know what the *main method* is doing, but it's a fantastic way to learn how to understand and build your own methods.

## 🌟 public (from [[5.3 - Access & Non-Access Modifiers]])
```java
	 PUBLIC static void main(String[] args)
```
Recall that ***public** makes the method accessible to other classes.*
This is important because... well this method is what the program does! So if another class needs the data from this program, then it'll need to be public

## 🌟 static (from [[5.3 - Access & Non-Access Modifiers]])
```java
	 public STATIC void main(String[] args)
```
Recall that ***static** makes the method apart of this class rather than an instance.*
This is important because we don't have an instance of the main class (basically, without it, we would need to write extra bits of code to make it work) -> To be expanded upon in [[6 - Classes & Objects]]

## 🌟 void (from [[5.2 Return Types]])
```java
	 public static VOID main(String[] args)
```
Recall that ***void** returns nothing*
This is because the program returns nothing, it only starts your program.

## 🌟 main
```java
	 public static void main(String[] args)
```
Alright so the *main* name is not arbitrary, Java looks specifically for a function called *main* and it must have these properties,

## 🌟 (String[] args) (from [[5.1 - Parameters & Arguments]] & [[2- Arrays]])

```java
	 public static void main(String[] args) 
                            ^             ^	 
```
Recall that within this context, *() is a parameter, and it's the values that it can accept during arguments*

**String[] args** basically means "I accept strings during program launch"
