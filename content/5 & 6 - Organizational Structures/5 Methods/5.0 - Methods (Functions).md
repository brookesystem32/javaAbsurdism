# Methods (Functions)![[Untitled design (12).png]]
### Syntax
```java
accessModifier returnType methodName(parameters) {
    // code
}
```
A **Method(Function)** is **essentially just a reusable block of code**. It's nice to think of it as the Java slogan *"**Write once, run anywhere"*** but applied only *within* the program's context. 

Another way to think of it, is **the program commiting an act**

```java
		public static void output(String input){
			System.out.println(input);
		}
```

then it can be called within the *main method* itself:

```java 
		public static void output(String input){
			System.out.println(input);
		}
		
		public static void main(String[] args){
			output("Hello World!");
			output("What's up world!");			
		}
```

It's most useful when a piece of logic is going to be re-used multiple times in a program and we're ~~too lazy~~ trying to make it more manageable:
```java
		public static int add(int firstNumber, int secondNumber){
			int sum = firstNumber + secondNumber;
			return sum; 
		}
		
		public static void main(String[] args){
			int firstValue = add(2, 3);
			System.out.println(firstValue);
			
			int secondValue = add(6, 9);
			System.out.println(secondValue)
		}
```

If we coded this without methods, then we would get a massive headache on our hands:
```java
		public static void main(String[] args){
			int firstNumber;
			int secondNumber;
			int sum;
			
			firstNumber = 2;
			secondNumber = 3;
			sum = firstNumber + secondNumber;
			
			int firstValue = sum;
			
			System.out.println(firstValue);
			
			firstNumber = 6;
			secondNumber = 9;
			sum = firstNumber + secondNumber;
			
			int firstValue = sum;
			int secondValue = sum;
			
			System.out.println(secondValue)
		}
```


The syntax of a Method (Function) is split into 5 parts:
1. [[5.3 - Access & Non-Access Modifiers]] - Can other parts of the program (or another file) access this?
2. [[5.2 Return Types]] - What value does it return once executed?
3. The name of the method - ... The name of the method?
4. [[5.1 - Parameters & Arguments]] - What values does it accept
5. The body / {} - The code itself
