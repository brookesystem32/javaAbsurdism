# Parameters & Arguments
![[Untitled design (11).png]]
Once we get to the *organizational structures* of programming languages, we start to refer to similar-ish concepts by two different names. As such, we tend to mix the terms up and start to anger a specific group of people: *nerds... or your boss...* To avoid this from happening, you should first know the first time this concept shows up: **Parameters & Arguments**.

Going back to our old example:
```java
		public static void output(String input){ //Parameter
			System.out.println(input); 
		}
		
		public static void main(String[] args){
			output("Hello World!"); // Arguments
		}
```
## 🌟 Parameters
```java
		public static void output(String input){ //Parameter
			System.out.println(input); 
		}
```
The 🌟 **Parameter** here would be `String input` located together within the  `void output` brackets! It could be thought of as the 🌟 **method's vessel of input data through a variable**; it sounds fancy but all it really means in practice is that it's *the only way for it to receive input*. 

When creating parameters, you must follow a couple of rules:
1. Now the word *variable* is important here, because as you may recall from [[2 - Courses/Java2/1 - Variables/1.2 - and Data Types...]], all variables 🌟 **must have a data type**. Likewise, **all parameters must have a data type**
2. All parameters 🌟 **must have a value**, either through **arguments** (i.e: receiving data) or by **assigning it already** (String name = "bob")
3. There's no limit to the amount of parameters you may have, you can have 0 or have 20.
## 🌟 Arguments
```java
		public static void main(String[] args){
			output("Hello World!"); // Arguments
		}
```
The **Argument** here would specifically be the `"Hello World!"` value within the `output()` brackets. Now if the **Parameters** were a vessel of input data, then the 🌟 **Argument** would simply be *the one providing the input data.*.

Luckily for us, the only thing to remember for argument are these two rules:
1. The data passed must be in sequential order of the parameters
2. The data must also be the same data type as the parameter
