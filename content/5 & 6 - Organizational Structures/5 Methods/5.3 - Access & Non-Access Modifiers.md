# Access & Non-Access Modifiers![[Untitled design (9).png]]
This is the most complicated part of the method's syntax because it pertains to concepts that we haven't really tackled yet - namely [[6 - Basic Object Oriented Programming (Class & Objects)]]. For the sake of sanity, you'll only have to start with at least **4** of them:

| Modifiers          | Meaning                                                                                                                                                    | Example                           |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| `public`           | Can be accessed from anywhere (most notably **outside of the file**)                                                                                       | `public void sayHello() { }`      |
| `private`          | Can only be accessed within its own class (for now, it means that it can only be accessed only within the file)                                            | `private void sayHello() { }`     |
| `static`           | Belongs to the class rather than an object (for now, it gives us the ability to actually run the method in the first place without extra code)             | `public static void sayHello(){}` |
| ` `_(no modifier)_ | Literally nothing, it can only be access within the same package (think of it as it can be accessed by all other files within the same folder in your IDE) | `void sayHello() { }`             |
Another thing to note is that *this isn't exclusive to only methods, it can apply to [[1 - Variables...]], [[2- Arrays]], and [[6 - Basic Object Oriented Programming (Class & Objects)]]*

If you're curious though of what lays ahead of you (or your teacher is asking you to memorize this), then here are the rest of the types:
# Access Modifiers

| Access Modifier | Meaning                                                           | Example                         |
| --------------- | ----------------------------------------------------------------- | ------------------------------- |
| `public`        | Can be accessed from **anywhere**                                 | `public void sayHello() { }`    |
| `protected`     | Can be accessed within the **same package** **and by subclasses** | `protected void sayHello() { }` |
| _(no modifier)_ | Can be **accessed within the same package**                       | `void sayHello() { }`           |
| `private`       | Can only be accessed from within its **own class**                | `private void sayHello() { }`   |
```java
// public
public float getLikeABeabadoobee() {
    return 10.36f;
}

// private
private float getLikeABeabadoobee() {
    return 10.36f;
}

// protected
protected float getLikeABeabadoobee() {
    return 10.36f;
}

// no modifier (package-private)
float getLikeABeabadoobee() {
    return 10.36f;
}
```

# Non - Access Modifiers

| Non-Access Modifier | Meaning                                                                                | Example                            |
| ------------------- | -------------------------------------------------------------------------------------- | ---------------------------------- |
| `static`            | Belongs to the class rather than a specific object                                     | `static void sayHello() { }`       |
| `final`             | Cannot be changed, overridden, or inherited depending on what it is applied to         | `final void sayHello() { }`        |
| `abstract`          | Declares something that must be implemented by a subclass                              | `abstract void sayHello();`        |
| `synchronized`      | Restricts a method so that only one thread can execute it at a time                    | `synchronized void sayHello() { }` |
| `native`            | Indicates that the method is implemented outside Java, usually in native code          | `native void sayHello();`          |
| `strictfp`          | Forces floating-point calculations to follow strict IEEE 754 rules                     | `strictfp void calculate() { }`    |
| `transient`         | Prevents a field from being serialized                                                 | `transient int age;`               |
| `volatile`          | Ensures a field's value is read from shared memory rather than being cached per thread | `volatile int count;`              |
| `default`           | Provides a default implementation for an interface method                              | `default void sayHello() { }`      |
```java
// static
static float getLikeABeabadoobee() {
    return 10.36f;
}

// final
final float getLikeABeabadoobee() {
    return 10.36f;
}

// abstract
abstract float getLikeABeabadoobee();

// synchronized
synchronized float getLikeABeabadoobee() {
    return 10.36f;
}

// native
native float getLikeABeabadoobee();

// strictfp
strictfp float getLikeABeabadoobee() {
    return 10.36f;
}
```
