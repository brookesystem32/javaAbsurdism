
# While Loops
![[You did ask for the 1st box! (4).png]]
### Syntax
```java
while (condition) {
    // Code to be executed repeatedly
}
```
Amongst the 3, the humble **while-loop** is the **most simple** and **foundational** one! It 🌟 **simply runs a block repeatedly as long the condition is true.**

Let's return to our previous example, but now we're all alone because everyone else is on vacation...
```java
    int age = 26; // you could use byte instead of int if you're really fancy;
    System.out.println("My age is " + age);
```

Now, if we want to display a message from his birthday then until his death. We can write it as so:
```java
    int age = 26; // you could use byte instead of int if you're really fancy;
    int deathAge = 30;
    while(age <= deathAge) { // While age is less than or equal to deathAge
        System.out.println("My age is " + age);
        age++; //or age = age + 1
    }
    if (age == deathAge){
        System.out.println("I have died!");
    }

```
```java
My age is 26

My age is 27

My age is 28

My age is 29

My age is 30

I have died!
```
*Shame he died so early...*

Anyways! What's going on under the hood is similar to just a series of repeating and iterating if-statements:
```java
if (age <= deathAge) {
    System.out.println("My age is " + age);
    age++; //27
}

if (age <= deathAge) {
    System.out.println("My age is " + age);
    age++; //28
}

if (age <= deathAge) {
    System.out.println("My age is " + age);
    age++; //29
}

if (age <= deathAge) {
    System.out.println("My age is " + age);
    age++; //30
}
```

And as such, if the condition is false... then the entire loop is skipped and he just dies!
```java
    int age = 67; // you could use byte instead of int if you're really fancy;

    }

```
```java

```
We didn't even get to know what his age was when he died! How rude!
