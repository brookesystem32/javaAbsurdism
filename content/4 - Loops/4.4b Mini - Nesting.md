# Nesting![[Untitled design (6).png]]
So [[3 - If Statements]] and [[4 - Loops]] *(and to some extent [[2- Arrays]] and [[6 - Basic Object Oriented Programming (Class & Objects)]] but shhhh that doesn't matter in this course)* have this unique ability called **Nesting**. This stems from the fact that both concepts are fundamentally about *running code blocks... and that also includes themselves.

You'll mostly see this concept applied in *if statements*
```java
int age = 18;

if (age >= 18) {
    System.out.println("You are an adult.");

    if (age >= 21) { // Will only execute if the age is both greater than or equal to 18 AND IF it's greater than or equal to 21.
        System.out.println("You are 21 or older.");
    }
}
```

You'll also see this concept applied in *loops*.
```java
for (int i = 1; i <= 3; i++) {

    for (int j = 1; j <= 3; j++) {
        System.out.println("i: " + i + ", j: " + j);
    }

}
/*Outer loop #1
    Inner loop #1
    Inner loop #2
    Inner loop #3

Outer loop #2
    Inner loop #1
    Inner loop #2
    Inner loop #3

Outer loop #3
    Inner loop #1
    Inner loop #2
    Inner loop #3*/
```
This application is *slightly* less common though (especially in this course) because this loop logic is primarily used to run through *ahem* **Dimensional Arrays** (Arrays within arrays).
