# Methods (Functions)
```java
accessModifier returnType methodName(parameters) {
    // code
}
```
A **Method(Function)** is **essentially just a reusable block of code**. It's nice to think of it as the Java slogan *"**Write once, run anywhere"*** but applied only *within* the program's context and with *some* special caveats.

```java
		public static void output(String input){
			System.out.println(input);
		}
```

then it can be called within the *main method* itself:

```java
		public static void output(String input){
			System.out.println(input);
		}
		
		public static void main(String[] args){
			output("Hello World!");
		}
```

The syntax of a Method (Function) is split into 5 parts:
1. [[5.3 - Access & Non-Access Modifiers]] - Can other parts of the program (or another file) access this?
2. [[5.2 Return Types]] - What value does it return once executed?
3. The name of the method - ... The name of the method?
4. [[5.1 - Parameters & Arguments]] - What values does it accept
5. The body / {} - The code itself

We do have to break **Rule 4** established back in [[0.2 - The Anatomy of the Basic Java Program]]  and make up some conjure up a new one, because *we're cool like that.* 

**New Rule 4:**
Any user-created method(function) must be within a class but not INSIDE another method. 
```java
	public class Main{
	
		public static void sayHello(){
			System.out.println("Hello!");
		}
		
		public static void main(String[] args){
			sayHello();
		}
}
```
*A fantastic example is the public static void main(String[] args){} **method**!*
