# Do-While Loops

```java
// DO-WHILE LOOP
do {
    // Code to be executed repeatedly
} while (condition);
```
A **Do-While** loop is basically just **a while loop *but* if the code ran once before the condition is applied.** It's similar to that feeling when you do something on auto-pilot and then you suddenly ask yourself why you're doing this. 

Alright back to the previous example but we switched the while loop to a do-while loop
```java
int age = 26; // you could use byte instead of int if you're really fancy;
int deathAge = 30;

do{

System.out.println("My age is " + age);
age++; //or age = age + 1

}

while(age <= deathAge); // While age is less than or equal to deathAge

System.out.println("I have died!");
```
```java
My age is 26

My age is 27

My age is 28

My age is 29

My age is 30

I have died!
```
Wait... *It's still the same?* 

Well yeah of course! A do-while loop acts similarly to a while loop if the condition was true to begin with!

But what if my man cheated death for a year? What if he surpassed the death age and was 31? t would be rude not to greet him! So what now?
```java
int age = 31; // you could use byte instead of int if you're really fancy;
int deathAge = 30;

do{

System.out.println("My age is " + age);
age++; //or age = age + 1

}

while(age <= deathAge); // While age is less than or equal to deathAge

System.out.println("I have died!");
```
```java
My age is 31
I have died!
```
As you may notice the loop underwent this process:
1. Execute the code
2. Check the conditions
3. Realize that you were wrong
4. Stop until it got any worse
