
# Return Types
### Syntax
```java
accessModifier returnType methodName(parameters) {
    return value;
}
```
If you recall what we tackled in [[3 - If Statements]], you'll remember that we used `return` as a way to (*intentionally*) stop the program from running any further! The word *return* might be a little strange though... why not *exit* or *leave* or even *stop*?

Well, that's because we utilized `return` *kinda in the way it's not supposed to.* In reality, stopping a program (more specifically **stopping a method**) is just one of its abilities. The main use for `return` is to **return values back**.

```java
public static int add(int a, int b) {
    return a + b;
}
```
As you may have noticed, the values that we're returning (a + b) is the same data type as the return type (int). This is a general rule for methods: **the return value must be the same as the return type.**

Fortunately for us, we can just grab the table from [[1.2 - and Data Types...]] and put it here! The return types / values of methods stem from that very table, with like one more type (*void*):

| Return Type | What it returns                           | Example Method                                                    |
| ----------- | ----------------------------------------- | ----------------------------------------------------------------- |
| `byte`      | A very small whole number                 | `static byte getBits() { return 8; }`                             |
| `short`     | A small whole number                      | `static short getHeight() { return 32; }`                         |
| `int`       | A whole number                            | `static int getLooks() { return 10000; }`                         |
| `long`      | A large whole number                      | `static long getPowerScale() { return 123124345213L; }`           |
| `float`     | A decimal number                          | `static float getLikeABeabadoobee() { return 10.36f; }`           |
| `double`    | A decimal number                          | `static double getMyIncome() { return 12.42345345d; }`            |
| `boolean`   | `true` or `false`                         | `static boolean makesSense() { return false; }`                   |
| `char`      | A single character                        | `static char getX() { return 'x'; }`                              |
| `String`    | Text                                      | `static String getEveryoneAdoresYou() { return "Atleast I do"; }` |
| `void`      | Nothing, the `return` keyword is optional | `static void sayHello() { System.out.println("Hello!"); }`        |
```java
public class Main {

    static byte getBits() {
        return 8;
    }

    static short getHeight() {
        return 32;
    }

    static int getLooks() {
        return 10000;
    }

    static long getPowerScale() {
        return 123124345213L;
    }

    static float getLikeABeabadoobee() {
        return 10.36f;
    }

    static double getMyIncome() {
        return 12.42345345d;
    }

    static boolean makesSense() {
        return false;
    }

    static char getX() {
        return 'x';
    }

    static String getEveryoneAdoresYou() {
        return "Atleast I do";
    }
    static void sayHello(){
	    System.out.println("Hello!")
	    // Optional
	    return;
    }

    public static void main(String[] args) {

        System.out.println(getBits());
        
        System.out.println(getHeight());
        
        System.out.println(getLooks());
        
        System.out.println(getPowerScale());
        
        System.out.println(getLikeABeabadoobee());
        
        System.out.println(getMyIncome());
        
        System.out.println(makesSense());
        
        System.out.println(getX());
        
        System.out.println(getEveryoneAdoresYou());
        
        sayHello();

    }
}
```
