## Variable Arithmetic ![[Untitled design (3).png]]
**Programming is deeply rooted in Mathematics** (as you may have already inferred), as such, we have to perform some Math whether we like to or not... 

Java provides special syntax to do this! **(*p.s: They're mostly self-explanatory, just remember that the modulus (remainder) sign is a percent sign (%) and you'll be a math wizard in no time!*)**

| 🌟 Operation           | Standard Operator | Standard Example | Shorthand Operator | Shorthand Example    | Equivalent To            |
| :--------------------- | :---------------: | :--------------- | :----------------: | :------------------- | :----------------------- |
| **Addition**           |        `+`        | `x = x + 5;`     |   `+=` or ``++``   | `x += 5;` or ``x++`` | Adds 5 to x              |
| **Subtraction**        |        `-`        | `x = x - 3;`     |   `-=` or ``--``   | `x -= 3;` or ``x--`` | Subtracts 3 from x       |
| **Multiplication**     |        `*`        | `x = x * 2;`     |       ``*=``       | `x *= 2;`            | Multiplies x by 2        |
| **Division**           |        `/`        | `x = x / 4;`     |        `/=`        | `x /= 4;`            | Divides x by 4           |
| **Modulus(Remainder)** |        `%`        | `x = x % 3;`     |        `%=`        | `x %= 3;`            | Finds remainder of x / 3 |

```java
// Addition
looks = looks + 500;      // standard
looks += 500;             // shorthand, same result

System.out.println("Looks after a glow-up: " + looks); // 11000

// Subtraction
height = height - 2;   // standard
height -= 2;                    // shorthand

System.out.println("Height after slouching: " + height); // 28

// Multiplication
powerScale = powerScale * 2;
powerScale *= 2;

System.out.println("Power scale after training arc: " + powerScale); // 492497380852

// Division
myIncome = myIncome / 4;
myIncome /= 4;

System.out.println("Income after taxes: " + myIncome); // 3.1058633625

// Modulus
bits = (bits % 3);  
bits %= 3;                 // shorthand

System.out.println("Bits leftover: " + bits); // 2

// Increment/Decrement shorthand
looks++;   // same as looks += 1

System.out.println("One more glow-up: " + looks); // 11001
```

## PEMDAS
For 99% of your programming journey, there'll only be one Mathematics rule that you'll need to take note of when performing operations: 🌟 **PEMDAS** *(PARENTHESES, EXPONENTS, MULTIPLICATION, DIVISION, ADDITION, AND SUBTRACTION.)* 
```java
int a = 2;
int b = 3;

System.out.println(a + b * 4);          // 14
System.out.println((a + b) * 4);        // 20

System.out.println(10 + a * b);         // 16
System.out.println(20 / b + a);         // 8

System.out.println(20 - b + a);         // 19
System.out.println(10 + a * (6 - b));   // 16

System.out.println(Math.pow(a, b) + 5); // 13.0

System.out.println(a); // Still 3
System.out.println(b); // Still 2
```

## 🌟 Variable Mismatch
I think this goes without saying, but **you can't really subtract a *Char data type* (a data type that can only hold characters: 'l', '1', ...) from *Integer data type* *(or multiply a word by a number, divide a number by a word, subtract a word from a word, etc etc.)*** Technically this is because of *Narrow & Widening Casting*, but a simpler explanation is...

*"🌟 How do you even **mathematically** perform operations with a word/letter and a number? Exactly, you can't."*
```java
char x = 'x';
byte isOne = 1;     
      
System.out.println(x - isOne); // Throws an incompatible data type error!
```

*Notice how I highlighted mathematically?* 
An odd exception is addition, you **can actually add numbers to a char/String** but it'll be **treated as a char/String, and not as a mathematical value.** 

🌟 This concept is called ***String Concatenation***
```java
char x = 'x';
byte isOne = 1;       
    
System.out.println(x + isOne); // Perfectly valid! Prints out "x1"
```
