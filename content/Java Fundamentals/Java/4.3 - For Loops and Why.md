# For Loops
### Syntax
```java
// FOR LOOP
for (initialization; condition; update) {
    // Code to be executed repeatedly
}

```

For Loops may look intimidating, but they're simply just *a much more condensed version of **the most common while loop pattern*:**
```java
// FOR LOOP
int i = 0; // it could be any variable, but traditionally it's called "i" for "iteration"
while (i <= maxLength){
	System.out.println(i);
	i++
}
```

```java
int maxLength = 10;
for(int i = 0; i <= maxLength; i++){
	System.out.println(i);
}
```

Now, you may be asking yourself: *Okay, so it's just a more complex looking while loop, why use it at all!?*

## Reason 1: Readability (Ironically)
If we have to use multiple *while loops* in a program instead of the normal for loop, then we would get this mess:
```java
// FOR LOOP
int i = 0; // it could be any variable, but traditionally it's called "i" for "iteration"
while (i <= 10){
	System.out.println(i);
	i++
}
System.out.println("First loop done! Moving on to the second one");

i = 0; // Reset back to zero
while(i <= 20){
	System.out.println(i);
	i++
}
```
You'll have to reset the value everytime, and if you intend to use the variable i for a totally different reason, then it would be incredibly annoying to keep track of the current value of it.

The for loop equivalent is much cleaner because the variable that it generates is locally scoped ([[3.2b Mini - Variable Scope]]), meaning that one loop's *int i* is different from another.
```java
for(int i = 0; i <= 10; i++){
	System.out.println(i);
} 
System.out.println("First loop done! Moving on to the second one");

for(int i = 0; i <= 20; i++){
	System.out.println(i);
} 

```


## Reason 2: Array Transversal
Remember [[2- Arrays]]? Well, remember how you can't properly print everything without calling a new *System.out.println()* for every item? 

Well I guess you can see where this is going...
```java
int[] ages = {26, 21, 20, 19};

for (int i = 0; i < ages.length; i++) {
    System.out.println("Person " + (i + 1) + "'s age is " + ages[i]);
    // Note: i + 1 doesn't affect the iteration, it only + 1 when it's being outputted (technicallyyyy it's passing an argument but that's for the next lesson so shhhhhh)
} 
```

Tada! you can even do some extra operations on all of the items in an array if you needed to:
```java
int[] ages = {26, 21, 20, 19};

for (int i = 0; i < ages.length; i++) {
    ages[i] += 10;
    System.out.println("Person " + (i + 1) + "'s age is now " + ages[i]);
}
```
