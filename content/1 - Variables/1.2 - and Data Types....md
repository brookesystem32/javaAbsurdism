## What Is A Data Type?
![[Untitled design (1).png]]
🌟 A **data type** tells the program what *kind of value a variable can store* (like a number, text, or true/false) and *determines how the data should be allocated in memory and what operations are allowed on it*. If a *variable* is a box, then the variable name (also known as an 🌟 **identifier**) is the label of that box, then the data type will determine what can go inside of it, how to allocate it, and what could be done to it. 

🌟 We have 2 types of data types: **Primitive and Non-Primitive / Reference** 

## 🌟 Primitive Data Types

A primitive data type is actually pretty much what our definition of *variables* were earlier: 🌟 **they hold simple raw values.** *A new type of primitive cannot be created by a programmer, what the language has listed will be the only primitives you could really only use.*

Here’s a table on the different primitive data types Java offers 
**note: For 90% of your programming journey, you will just use int, double, boolean, chars, and strings. Do not get stressed over the amount of data they hold just yet.**

| Primitive Data Types | Description:                                                                                                                                                                                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **🌟 byte**          | Stores whole numbers from -128 to 127                                                                                                                                                                                                                          |
| **short**            | Stores whole numbers from -32,768 to 32,767                                                                                                                                                                                                                    |
| **🌟 int**           | Stores whole numbers from -2,147,483,648 to 2,147,483,647                                                                                                                                                                                                      |
| **long**             | Stores whole numbers from -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807<br><br>All values must end with the suffix “L”                                                                                                                               |
| **float**            | Stores decimals. Sufficient for storing 6 to 7 decimal digits<br><br>All values must end with the  “f” suffix and whole numbers are allowed but are seen as decimals (1f = 1.0)                                                                                |
| **🌟 double**        | Stores decimals. Sufficient for storing 15 to 16 decimal digits<br><br>If a decimal value doesn’t end with an “f” suffix, then Java will assume that it’s a double and treat it as such. Doubles can have whole numbers but they’re seen as decimals (1 = 1.0) |
| **🌟 boolean**       | Stores true or false values                                                                                                                                                                                                                                    |
| **🌟 char**          | Stores a single character/letter <br><br>Value must be wrapped in single quotes (‘’)                                                                                                                                                                           |
|                      |                                                                                                                                                                                                                                                                |

Here’s all of them in code:
```java
        byte bits = 8;  
        
        short height = 32;  
        
        int looks = 10000;  
        
        long powerScale = 123124345213L;  //You gotta use 'L' at the end of long variables
        
        float likeABeabadoobee = 10.36f;  //You gotta use 'f' at the end of float variables 
        
        double myIncome = 12.42345345d;  //You gotta use 'd' at the end of float variables 
        
        boolean makesSense = false;  
        
        char x = 'x';  
        
        String everyoneAdoresYou = "Atleast I do"; // Strings are actually non-primitive data types but they can be used as simple as this!
```
## (OPTIONAL) Non-Primitive Data Types / Reference Types

If *primitive data types hold only a single simple value*, then **non-primitive data types** (or otherwise known as **reference types**) can **contain many similar values**. Unlike primitive data types, you could create your own non-primitive data type alongside Java's inbuilt ones.

The table below lists all of the *Java Non-Primitive Data Types*, though take note: **for the purposes of this section, you must only worry about Strings and Arrays. IGNORE THE COMPLEX STUFF UNTIL WE GET THERE! "JUST TRUST US"**

| Non-primitive  | Description:                                                                                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **🌟 String**  | Can be simply thought of as a collection of "char" data type, similar to how *words are simply just a group of letters.*                                          |
| **Array**      | A group of variables or values  that can be accessed by a single variable.  [[2- Arrays]]                                                                         |
| **Classes**    | A blueprint from which objects are created.  It represents the set of properties or methods that are common to all objects of one type. [[6 - Basic Object Oriented Programming (Class & Objects)]] |
| **Objects**    | These are the actual objects created by the classes. [[6 - Basic Object Oriented Programming (Class & Objects)]]                                                                                    |
| **Interfaces** | A simple template applied to a class.                                                                                                                             |
