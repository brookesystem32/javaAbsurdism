### Syntax
```java
public class Main{  
    public static void main(String[] args) {  
      // Your code here  
    }  
}
```
We all start somewhere, and for Java, it decided to start out as that monster of a body!

Fortunately for us, we can literally just be ignorant and **ignore what *public class Main & public static void main(String[]args)* means first!** Yes, you heard me right! The first thing you ever learn in Java programming is to 🌟 **ignore the elephant in the room.** It's not without *good reason though...* What you're seeing here are [[6 - Classes & Objects]] and [[5.0 - Methods (Functions)]] in action; Tackling them right now without a good foundation will be... well bad...

What you do need to know are the following rules:
1. Java and other programming languages read code from **top to bottom, left to right.**  
2. **FOR NOW**, insert all of your code within the **public static void main(String[] args)** *method*'s (Also to be discussed in  [[5.0 - Methods (Functions)]] )curly brackets {}
3. 🌟 **Lines of code** that doesn't end with curly brackets "{}" **must end** with a **semi-colon ";"** as this tells the computer that the line finished executing and it's time to move on to the next!

# So basically...
```java
public class Main{  
    public static void main(String[] args) {  
      // ONLY PLACE YOUR CODE HERE FOR NOW! <<<<<<<<<<<<<<<<<<<<<<<<<<<<
    }  
}
```

## Examples!
**Correct** program: (we’ll assume the file name is **Main.java**):  
```java
  public class Main{ // public class Main is the same as the file name  
  
    public static void main(String[] args) {  
// All of the code is within public static void curly braces  

        System.out.println("Hello world!");  

        System.out.println("Hello world!");  // It’ll just print out hello world twice  
  
  } // All of the code is within public static void curly braces  
  
}// public class Main and public static void main(String[] args) are present
```

**Incorrect** (again we’ll assume that the file name is **Main.java**):
```java
public class Subs{ // Name is not the same as file name, error 1  

    System.out.println("Hello, World!"); // Not within the public static void main! It won't run! error 2
    
    public static void main(String[] args) {  
    
       System.out.println("Hello, World!"); //Correct! but it won't run because there are glaring issues
       
    }  
}
```

```java
public class Main {  

        int a = 2; // Not within the public static void main! Error 1!
        
    public static void main(String[] args) {  
    
        System.out.println("hello" + a) // No semicolon so it throws an error since it doesn’t know when to stop.  Error 2!
        
    }       
}
```
