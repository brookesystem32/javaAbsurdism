### Syntax
```java
	// Inline / Single Line
	
	/* Multi-line 
	comment.
	 */
	 
	/** 
	* Documentation 
	* Comment
	* for explaining Methods, classes, and other stuff
	*/
```
We will start your coding journey by... not actually coding anything yet. We need to gather up some basic information first, don't worry you'll get this in no time.

**The reason why you need to learn this first above all else is because each program example in this entire course has comments that reveals the output or some extra explanation of the particular line.** If you don't know how to read comments, then you're going to be rather lost... especially as a beginner!

Fundamentally, 🌟 **Comments** are **simply *just lines of code that the program doesn't read, and thus we can pretty much write whatever we want.*** For programmers, **we use it primarily to explain code**
## 3 Types of Comments
1.🌟 **Inline / Single Line(//) - Comments for the end or beginning of a line of code**
```java
public class Main {

    public static void main(String[] args) {

      System.out.println("hello" ); // What’s the name of that one clairo song again?

    }      

}
```

2. 🌟 **Multi-line (/* \*/) - Comments that drag on for multiple lines**
```java
public class Main {

    public static void main(String[] args) {

/*

 * Girl, there must be a reason you let it slip

 * Went to the point of sending the message

 * Six months of visceral Catherine Wheels

 * Kissing carnivores to make it seem less of a deal

 * Just let me be the one that keeps track on the moles on your back

 * I just sighed, the universe replied:

*/

        System.out.println("Let this pass you by." );

    }      

}
```

3. 🌟 **Documentation (\/\*\* \*\/\) - They are placed strictly before classes, interfaces, fields, or methods to describe their purpose.**
```java
/**
 * Calculates the area of a rectangle.
 * @param width The width of the rectangle.
 * @param height The height of the rectangle.
 * @return The total calculated area.
 */
public int calculateArea(int width, int height) {
    return width * height;
}

```
