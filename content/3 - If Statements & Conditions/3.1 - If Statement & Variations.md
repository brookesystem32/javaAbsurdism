# If Statements Variations![[Untitled design (2) 3.png]]
### Syntax
```java
if(condition){
	System.out.println("This condition is true!);
}

// Or if you want something to happen if the condition is false

if(condition){
	System.out.println("This condition is true!);
} else {
	System.out.println("This condition is false!);
}

// OR if you want something *specific* to happen if the condition is false

if(condition){
	System.out.println("This condition is true!);
	
} else if (secondCondition) {
	System.out.println("The second condition is true if the first condition is false!);
	
} else {
	System.out.println("Both conditions are false!");
}
```

The programming concept that everyone (*yes, including your boss*) is totally familiar with is If Statements, and it's for a good reason: *it's actually as simple as it seems.* 

🌟 Fundamentally, an **If Statement** will **run a piece of code IF a condition is met [[3 - Condition(al Operators)]].**  
```java
// If the condition is true
if(10 > 7){
	System.out.println("10 is greater than 7!"); // 10 is greater than 7!
}

// If the condition is false
if(isHandsome == true){
	System.out.println("Author is handsome!"); // The condition is false, and it will skip this.
}
```

## 🌟 Variations
Each variation of the If Statement simply asks the question: ***what will happen if the INITIAL condition is false?***

| Structure      | Description                                                                    | Example                                              |
| -------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------- |
| `if`           | Runs code **if a condition is true**. If false, the code is skipped.           | `if (age >= 18) { ... }`                             |
| `if / else`    | Runs one block if the condition is **true**, and another if it is **false**.   | `if (age >= 18) { ... } else { ... }`                |
| `if / else if` | Checks **multiple conditions in order**. The first true condition is executed. | `if (age >= 18) { ... } else if (age >= 13) { ... }` |

### 🌟 If Statement
This will simply 🌟 **skip** the entire block if the initial condition isn't met
```java
// If the condition is true
if(10 > 7){
	System.out.println("10 is greater than 7!"); // 10 is greater than 7!
}

// If the condition is false
bool isHandsome = false;
if(isHandsome == true){
	System.out.println("Author is handsome!"); // The condition is false, and it will skip this.
}
```

### If / Else Statement
This will 🌟 **execute another block** if the initial condition isn't met. 
```java
// If the condition is true

if(10 > 7){

	System.out.println("10 is greater than 7!"); // 10 is greater than 7!
	
} else {

	System.out.println("10 is NOT greater than 7!"); // Won't execute because 10 is ALWAYS greater than 7
	
}


// If the condition is false

bool isHandsome = false;

if(isHandsome == true){

	System.out.println("Author is handsome!"); // The condition is false, and it will skip this.
	
} else { // This will execute!

	System.out.println("The Author is... okay looking?"); // The Author is... Okay Looking?
	
}
```

### If / Else If Statement
This will 🌟 **execute another statement** if **the initial condition isn't met** but if **another condition is met.** *If there must be an else statement, then place it at the end of the logic.* 
```java
// If the condition is true
if(10 > 7){

	System.out.println("10 is greater than 7!"); // 10 is greater than 7!
	
} else if (6 != 7){

	System.out.println("6 is not equal to 6!"); // Won't run since 10 > 7 is true (and this condition is already false!)
	
else{

	System.out.println("10 is NOT greater than 7!"); // Won't execute because 10 is ALWAYS greater than 7
	
} 


// If the condition is false

bool isHandsome = false;

if(isHandsome == true){

	System.out.println("Author is handsome!"); // The condition is false, and it will skip this.
	
} else if (name == "Brooke" || name == "System"){ // This will execute!

	System.out,println("This guy is funny though!");

} else if (name == "Edic"){

	System.out.println("Yeah he's not handsome... he's pogi!");
	
}

else { 

	System.out.println("The Author is... okay looking?"); // The Author is... Okay Looking?
	
}
```
