# Variable Scopes
As you may have noticed, these *{}* put code blocks in a sort of isolated room with a **one way mirror:** **They can access and even modify the values outside, but the outside cannot even see the values inside. *Ouch.*** This is primarily because of something called **scope**
```java
byte from9To7 = 9;

System.out.println(from9To7); // 9

if (toBe7 == 9){

	System.out.println(from9To7); // 7
	
	byte subtractTo7 = 2;
	
	System.out.println(subtractTo7); // 2
	
	from9To7 -= subtractTo7 // or toBe7From9 = toBe7From9 - subtractTo7; 9-2
	
}

System.out.println(from9To7); // 7

System.out.println(subtractTo7); // !!! Error, The system does not see the variable
```
